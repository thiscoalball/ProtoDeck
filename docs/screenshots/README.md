# ProtoDeck 界面预览 / UI previews

本目录中的图片由 Flutter 截图测试自动生成，不需要在手机上逐页手工截图。测试使用内存
数据库、英文浅色主题和固定视口，不包含真实设备、账号、远程主机或网络扫描数据。

The images in this directory are generated by Flutter screenshot tests. They
use an in-memory database, the English light theme, and fixed viewports. No
real device, account, remote host, or scan data is included.

## 桌面布局预览 / Desktop layout previews

- `desktop-home.png`
- `desktop-tools.png`
- `desktop-api-workbench.png`
- `desktop-remote.png`

上面每个桌面文件也都有对应的 `-zh.png` 中文版本。Each desktop file also
has a Simplified Chinese `-zh.png` variant.

桌面图片用于验证 ProtoDeck 在 `1440 × 900` 下的响应式 Flutter 布局，不应作为 Windows
原生能力的实机证明。网卡、蓝牙、文件选择器和终端行为仍需在对应系统上验证。

Desktop images validate ProtoDeck's responsive Flutter layout at `1440 × 900`.
They are not native Windows runtime evidence. Networking, Bluetooth, file
pickers, and terminal behavior still require verification on the target OS.

## 重新生成 / Regenerate

在 `app` 目录执行 / Run from `app`:

```bash
./tool/generate_docs_screenshots.sh
```

也可以指定 Flutter / Or specify Flutter explicitly:

```bash
FLUTTER_BIN=/path/to/flutter ./tool/generate_docs_screenshots.sh
```
